# CMPS664_Project1

The following repositoryu is an interactive database normalization tool via python as well as a testing file.

The python script goes through the five following steps.

1. Import CSV data via file name
2. Identifies functional dependencies of a given csv file using user defined dependencies
3. Automatically normalize tables into 3NF via results from step 2.
4. Generate an SQL script to automatically create and populate tables in excel using the normalized tables from step 3.
5. Run the scripts from step 4 using an sql connection.
